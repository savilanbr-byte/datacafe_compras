# DataCafé

App instalable (PWA) para compra de café en Colombia: calculadoras de pergamino y cereza, precios de mercado, calendario de cosechas, catación con reporte PDF, noticias y clima.

- `index.html` — la app completa.
- `data/mercado.json`, `data/noticias.json`, `data/clima.json` — datos de mercado, noticias y clima (también `data/cosechas.json` y `data/historico.json`).
- Las cataciones se guardan solo en el teléfono de cada persona.

Publicada con GitHub Pages (rama `main`, carpeta raíz).
Dirección: https://savilanbr-byte.github.io/datacafe_compras/
